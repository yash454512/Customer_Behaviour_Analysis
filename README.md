# 📊 Customer Shopping Behavior Data Analytics Project

## 📌 Overview

This project demonstrates an end-to-end Data Analytics workflow using Python, SQL, and Power BI. The objective is to analyze customer shopping behavior, clean and transform the data, perform exploratory data analysis (EDA), execute SQL queries for business insights, and build an interactive Power BI dashboard. The project also includes a detailed analytical report and presentation.

---

## 📂 Dataset

The dataset contains customer shopping behavior information, including:

- Customer Details
- Age & Gender
- Product Categories
- Purchase Amount
- Payment Method
- Shopping Frequency
- Discounts Applied
- Customer Ratings
- Purchase History

**Dataset Type:** Customer Shopping Behavior Dataset

## ▶️ How to Run

### Clone the Repository

```bash
git clone https://github.com/your-username/customer-shopping-behavior-analytics.git
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run the Notebook

Open:

```
Customer_shopping_Behaviour.ipynb
```

Run all cells sequentially.

### Execute SQL Queries

- Import the dataset into PostgreSQL, MySQL, or SQL Server.
- Run the queries from:

```
customer_behaviour.sql
```

### Open Power BI Dashboard

Open:

```
powerBi.pbix
```

using **Microsoft Power BI Desktop**.
